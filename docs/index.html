Deutsch napi gyakorló

GitHub kapcsolat

A napi eredmények mentéséhez és a friss előzmények olvasásához egy GitHub Personal Access Token szükséges, ami csak erre a repóra szól (Contents: Read and write jogosultsággal). A token csak ebben a böngészőben, a te gépeden tárolódik (localStorage), sehova máshova nem kerül elküldésre a GitHub API-n kívül.

Nincs még tokened? Token létrehozása előre kitöltött űrlappal – a repó, a jogosultság (Contents: write) és a lejárat már ki lesz töltve, csak az "Only select repositories" alatt válaszd ki a repót, majd "Generate token", és másold ide az eredményt.
